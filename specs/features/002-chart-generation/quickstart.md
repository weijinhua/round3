# Chart Generation Quickstart

1. Start the web app and API.
2. Open the dashboard at `/dashboard`.
3. Enter a prompt such as `Q1 12, Q2 18`.
4. Click `Generate` to render the chart preview.
5. Switch the chart type with the type buttons and confirm the preview updates with the same data.
6. Click `Save` to add the chart to history.
7. Click `Export` to download the SVG artifact.
8. Confirm the saved chart appears in the history sidebar.

## Verification

- A preview appears for a prompt with labels and numeric values.
- Changing the chart type keeps the same data points.
- Saved charts show up in the sidebar history.
- Export returns an SVG file for the saved chart.
